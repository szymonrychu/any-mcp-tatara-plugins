# any-mcp-tatara-plugins memory

Lessons that outlive a session. Newest first.

- 2026-11-01 (superleader-crud PL2 fix round 1): `to_file` is confined to `secrets_dir` (default `~/.agent-secrets`, created 0700, real paths compared so symlinks and `..` fail), refuses an existing file unless `overwrite: true`, never follows a symlink target. `preset_create`, `preset_replace` and `session_create` refuse a protected env entry with a `value` (error names the variable, points to `secret_set`) before any request: the open `spec` schema would otherwise carry it into the transcript.

- 2026-11-01 (superleader-crud PL2): `secret_set` is registered by `load_tools` and `SecretResolveError` is routed in `on_error` (text `<tool> failed: <class>`). `to_file` is not a separate local tool: the four webhook tools that can receive an issued credential stay declarative rows and `OrchestratorPlugin.call` wraps them (pops `to_file`, validates it before any request, sends `X-Orch-Tool: local` only when it is given, drops `credential` from every answer, writes it with `write_credential`: 0600 temp file in the target directory then `os.replace`). Why: reuses the binding, path filling and upstream error mapping instead of a second HTTP path. The tool is named `secret_set` as in L1 (the plan text says `preset_secret_set`). Protected-only is enforced by the orchestrator (422 for a name that is not a protected variable); the plugin does not duplicate that check.

- 2026-11-01 (superleader-crud PL1): the admin tools are rows in `admin.py` (`AdminRow`), not hand-written `spec()` calls, so one table feeds `load_tools` and the contract test. The test pins method and path (parameter names normalised) of every http tool to `tests/fixtures/orchestrator_openapi.json`, a /agent/v1-only extract of the orchestrator's `openapi.json` (superleader-admin 461a85d); refresh it when the orchestrator API changes. Relay routes have no request schema upstream, so row schemas come from the upstream services' committed OpenAPI documents and are closed (`additionalProperties: false`). No row takes a `password`: webhook credentials are issued by the upstream and stored by the orchestrator. Chat admin tools are named `chat_admin_*`/`chat_rule_*` to avoid the user-chat tools `chat_rooms`/`chat_send`.

- 2026-10-31: non-declarative (local) tools in any-mcp: a `ToolSpec` with `handler=async (ToolCall) -> value` instead of `http=`; the `Plugin.call` hook runs the handler, so the arguments stay in-process. `orchestration/orchestrator/.../secrets_local.py` builds `secret_set` this way (`local_secret_tool`); `Plugin.on_error` hides exception text, so the plugin's `on_error` must route `SecretResolveError` to `secret_error_result` (PL2 wires both into `load_tools`). Errors carry fixed class names only, never value, path or command output.
